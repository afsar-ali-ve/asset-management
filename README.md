A modern admin-dashboard web application for managing IT assets, built with React + Vite (frontend) and Node.js + Express + Prisma (backend).

Projet setup Instruction:
Install all dependencies by running: npm run install:all

If you encounter any dependency-related issues, run: npm audit fix

Start the project using: npm run dev

If Prisma crashes or generates schema-related errors, run the following command in the backend workspace: npm run db:generate --workspace backend
